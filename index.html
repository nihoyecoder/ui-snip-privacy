UI Snip Beta — Privacy Policy

Effective November 15, 2026. UI Snip Beta is a Chrome extension, made by Manoj Singh Rawat. It turns a design, a motion, or an animation on a web page into a prompt for AI coding tools. For questions, write to manojsinghrawat0003@gmail.com.

This policy describes version 0.1.0 of UI Snip Beta, as published in the Chrome Web Store. To see your version, open chrome://extensions.

The short version

  • Everything happens in your browser. UI Snip Beta reads a page only when you start one of its tools there, and only the part you choose. It makes its prompts on your computer.
  • Its AI isn't available yet. The AI buttons are there, but what you capture is never sent: not to UI Snip's server, and not to Google.
  • Nothing is stored. UI Snip Beta keeps nothing in your browser's storage, and has no accounts, analytics, ads, or tracking.
  • Never sold. UI Snip Beta doesn't sell data, and doesn't use it for advertising or credit decisions.

What UI Snip Beta reads, and what stays on your computer

UI Snip Beta works only on the tab where you click its toolbar button, and only after you choose a tool. Chrome lets it work there until you leave that page.

Select Design

  • While you choose, it follows your pointer to highlight the element under it.
  • For what you choose (an element, a section, or the whole page), it reads:
    • layout and sizes;
    • fonts, colors, spacing, borders, and shadows;
    • transitions and image sizes;
    • structure: tag names, class names, and ids.
  • Text is described, not copied. It notes each text's role and length, never its words. It doesn't read form values or text you're editing.
  • It takes a screenshot of what you chose. The screenshot shows whatever is visible there, including any text or images.
  • It writes a prompt from what it read. The prompt doesn't include the page's words or its address.

Capture Motion

  • You draw an area on the page. The first time, Chrome asks you to allow tab capture.
  • It records after a 3-second countdown: the tab, for up to 5 seconds, as video only, with no sound. It keeps frames of the area you drew.
  • It makes a storyboard image from the frames.
  • Generate prompt tries the AI first. The AI isn't available, so UI Snip Beta then writes the prompt itself, asking your coding tool to read the storyboard.

Inspect Animation

  • You choose an element, then make its animation happen, for example by hovering, clicking, focusing, or scrolling. UI Snip Beta watches for up to 5 seconds.
  • It reads what Chrome reports about the element's animations (their timing, easing, and keyframes). It also measures how the element, and some of its parts, change.
  • It notes your interaction, to work out what started the animation:
    • the position of your pointer;
    • when you press and release it;
    • how the page, or a part of it, scrolls;
    • whether the element is hovered or focused;
    • which classes the page adds or removes;
    • the names, but not the values, of other attributes that change.
  • It never records keystrokes, form values, or page text.
  • It writes a report and a prompt. The report names the likely trigger, such as a hover or a click, and when it happened. It doesn't include your pointer's path.

What stays on your computer

  • In memory only: screenshots, frames, storyboards, reports, prompts, and the interaction notes above. They're gone when you start over, leave or reload the page, or close the side panel.
  • What you save yourself: copying puts a prompt or an image on your clipboard. Downloading saves an image (a screenshot, a frame, or a storyboard) to your downloads folder.
  • Nothing in storage: UI Snip Beta keeps no settings, history, or other data in your browser's storage.
  • The site's name (its hostname) shows in the side panel while you work, so you know which page you're on. UI Snip Beta doesn't keep it or send it anywhere.

The AI buttons

UI Snip Beta shows three AI buttons: Generate prompt in Capture Motion, and Enhance with AI in Select Design and Inspect Animation. The notice beside each says what it would send to Google's Gemini: that Google may use it to improve its products, and that people at Google may read it. That describes how the AI is meant to work. In this version, the AI isn't available:

  • The check. When you click an AI button, UI Snip Beta prepares the image or report on your computer. Chrome then asks UI Snip's server whether the request may be sent.
  • The refusal. The server doesn't accept requests from this version, so Chrome stops there.
  • What's sent: nothing you captured, to UI Snip's server or to Google.
  • What you see: "Couldn't reach the AI", and UI Snip Beta keeps or writes its own prompt instead.
  • What the check carries: no content. Only what any web request carries: your IP address, details of your browser, and that the request comes from UI Snip Beta.

Before UI Snip's AI becomes available, this policy will be updated to say what's sent, to whom, and the choices you'll have.

UI Snip's server and Cloudflare

UI Snip's server runs on Cloudflare Workers.

  • The server keeps nothing from the checks above.
  • Cloudflare handles your IP address and the request in order to deliver them, under its own privacy policy.
  • Live logs: when fixing a problem, the developer can watch live request information from Cloudflare, such as the time, the IP address, the country, and the browser of each request. It never includes what you captured, and UI Snip doesn't save it.

Your choices

  • Use it without AI. Every tool works without it.
  • Remove UI Snip Beta. Open chrome://extensions and click Remove. It keeps nothing in your browser's storage, so nothing is left behind.
  • Delete what you saved. Prompts and images you copied or downloaded are yours to delete.

Children

UI Snip Beta isn't meant for children.

Changes

If this policy changes, the new version will be posted here, with a new effective date. It will change before UI Snip's AI becomes available.
